# TMR Control Panel

**TRINITY MATH RESEARCH** の手動運用ツール（v0.3）

> 問題をぼかす → ぼやけた知識で見合わせる

---

## これは何か

TMR（Trinity Math Research）は、数学の問題を「解く」ことよりも、**問題の構造と知識の構造を抽象化して接続を探す**ことを目的とした研究支援の構想です。

このリポジトリでは、構想を実際に試すための**完全オフライン・手動連携ツール**を公開しています。

- 複数のAI（Researcher A〜D / Monitor / Validator / Normal）を別々のチャットで動かす
- プロンプトを生成してコピー
- 回答を保存・集約
- 候補の検証用プロンプトを作る

すべてブラウザ内で完結し、API接続は一切ありません。

---

## 使い方

1. [Control Panelを開く](https://akarasaman.github.io/tmr-control-panel/)
2. 「① 実験設定」で問題文を入力
3. 「② 指示を生成」で各AI用のプロンプトを作ってコピー
4. 各AIの別チャットに貼り付けて回答を得る
5. 「③ 回答を保存」に原文を貼る
6. ROUNDを進めながらMonitorやValidatorを使う

データはこのブラウザのlocalStorageに自動保存されます。定期的に「バックアップを書き出す」でJSONを保存してください。
